# Power BI Sales Dashboard & Data Storytelling

> **Portfolio focus:** Power BI • Business Intelligence • Sales Analytics • Data Visualization

## Business Problem

Sales data is difficult to act on when key trends are spread across raw transactional records. This project builds a Power BI dashboard to help stakeholders understand category performance, regional profitability, customer contribution, sales trends, and segment mix.

## Objective

Create a clear, interactive dashboard that converts Superstore sales data into business-ready visual insights.

## Dataset

- **Dataset:** Sample Superstore
- **File:** `Sample - Superstore.csv`
- **Source noted in the original project:** Kaggle

## Tools

- Power BI Desktop
- CSV data
- GitHub for version control and portfolio presentation

## Workflow

1. Import the Superstore dataset into Power BI.
2. Inspect and prepare fields for analysis.
3. Build visuals around sales, profit, category, region, customer and segment performance.
4. Add time-based analysis for monthly sales trends.
5. Organize visuals into a stakeholder-friendly dashboard.
6. Document the resulting business insights.

## Dashboard Analysis

The project includes visual analysis for:

- Sales by Category
- Profit by Region
- Sales vs. Profit by Sub-Category
- Monthly Sales Trend
- Top 10 Customers by Sales
- Segment-wise Sales

## Key Insights

The original project documents these findings:

- Technology has the highest sales.
- The West region is the most profitable.
- Office Supplies underperforms.
- The B2C segment contributes the most revenue.

## Business Recommendations

Based on the documented findings:

1. Protect and scale high-performing Technology sales opportunities.
2. Investigate what operational or commercial factors are supporting West-region profitability.
3. Review pricing, assortment and cost structure for Office Supplies.
4. Continue monitoring segment-level sales mix to understand where revenue concentration is strongest.

## Results

The deliverable is a Power BI dashboard designed to communicate sales and profitability patterns through a small set of business-focused visuals.
